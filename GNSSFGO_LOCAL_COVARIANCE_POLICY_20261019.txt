User decision
-------------
Always use LOCAL covariance for outgoing source beliefs, including later
stable-ID revisions supplied to gnssFGO. Do not switch from LOCAL to MAIN
posterior covariance merely because the message is a revision.

Contract for GLIM and Kimera, CBS-OFF and CBS-ON
----------------------------------------------
1. Preserve the current corrected source relative mean from MAIN.
2. Recompute the full6x6 LOCAL relative covariance for the same physical
   endpoints and source update. Preserve [phi,rho] right-local coordinates,
   full cross terms, and chart transport to the current endpoint estimates.
3. LOCAL means native source information and native marginal history, without
   explicitly received peer factors. Maintain separate history when MAIN's prior
   is not native-only; a redundant copy is not required when removal-before-
   elimination proves native provenance (CP-I2 below). It does not mean
   merely deleting visible CBS slots while copying an externally conditioned
   MAIN marginal prior. Verify each source's actual implementation; do not
   certify a path solely because a parameter or class is called LOCAL.
4. Preserve revised means AND revised LOCAL covariances. Do not freeze the
   first matrix, discard useful revisions, or reconstruct covariance from a
   saved trajectory.
5. gnssFGO keeps the existing stable-ID replacement/lifecycle. No duplicate
   factors, added covariance scale, gate, robust loss, Qc/prior/timing change,
   or central IMU is introduced by this policy decision.
6. If LOCAL covariance is unavailable, report an explicit query failure under
   the diagnostic failure policy; never silently substitute MAIN covariance.
7. Keep source-to-source classic CBS separate from downstream diagnostic
   revisions. This decision does NOT enable source-to-source live_revision.

Rationale and limits
--------------------
The receiver should not silently re-import explicit peer-factor precision
inside a source covariance while also accepting the peer's own beliefs as
separate factors. Consistent native-information conditioning is the intended
compression policy, rather than alternation between native and MAIN posterior.

This is NOT a proof of statistically independent measurements or perfectly
calibrated uncertainty. Corrected MAIN means, linearization points, selected
correspondences, past nonlinear history and shared CPT7 IMU can still carry
common information. LOCAL covariance around a corrected MAIN mean is a declared
approximation, not the exact posterior covariance of that MAIN estimate.
The EIG-2 first-publication confidence blind spot can remain under this policy.
No accuracy improvement is promised by this decision.
