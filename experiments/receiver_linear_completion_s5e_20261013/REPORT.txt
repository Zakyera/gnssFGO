What was isolated
-----------------
At each selected publication, copy iSAM2 BEFORE authoritative refinement.
On the saved copy, obtain:
 A: calculateEstimate() — ordinary wildfire-limited delta.
 B: calculateBestEstimate() — full back-substitution of the SAME linear system.
No update(), factor insertion/removal, Jacobian rebuild or nonlinear iteration
is allowed in B. Original strict refinement runs independently and publishes
exactly as before. The diagnostic cannot commit B.

Fresh objective/gradient verification is separate from B's linear solve:
clone source factors with endpoint caches disconnected, slice the whole-factor
memo wrapper off motion/source factors, preserve identical keys/means/noise/
equations. Clone priors. Unknown factor types fail closed. This avoids altering
the authoritative solver's shared factor caches. Source noise pointers are
immutable and identical. Tests verify exact residual/Jacobian/gradient/diagonal
equality, including dense covariance and null factor slots.
Only additional public helper in the private SourceWnoaModel copy is an
uncached diagnostic clone; existing authoritative evaluation code is unchanged.

Compare B against S5d's A, first global nonlinear pass, and final accepted state
at the identical physical timestamps and information set. All18 initial states,
objectives and EVERY gradient/diagonal coordinate match S5d exactly. This also
validates that copying a pre-refinement solver and examining it later did not
change the snapshot's contents.

API finding
-----------
See API_NOTES.txt for pinned4.2a8 headers/library hashes, not another local
GTSAM4.3 tree. Installed ISAM2.h distinguishes the incomplete estimate from
complete back-substitution. ISAM2-impl.h:386-387 explicitly changes the
relinearization check to threshold0.0 when update.forceFullSolve is true.
Our FullPublicationRefinement wrapper sets both force_relinearize=true and
forceFullSolve=true on its nonlinear trials. Thus it requests global eligible
state relinearization, NOT merely a complete solve of the already-built system.
This strict wrapper is our experimental receiver policy, not a universal
gnssFGO/GTSAM requirement. These facts do not establish the authors' deployment
timings or make their experiments a controlled benchmark for this receiver.

Interpretation and stop
-----------------------
The cheap full-linear-solve shortcut is NOT sufficient under the frozen model
and strict publication rule. Necessary nonlinear correction remains; this is
not evidence that every historical factor must be rebuilt on every pass.
Together with S5c/S5d, the bottleneck is the custom repeated full-history
nonlinear refinement/gradient/QR work, not an intrinsically slow ~3ms backsolve.

Do not remove strict refinement, relax its threshold, or promote B based on
these snapshots. They inherit all earlier strictly refined history. The old
live-versus-offline discrepancy remains unresolved; E4 selective-trial failure
remains rejected. No new production policy has been validated.

Next bounded choice, not executed: reduce the cost of the necessary nonlinear
work while retaining exact equations/gates (the plan's isolated motion V/W
Jacobian step E3a is still a candidate). If redesigning incremental publication
instead, it requires a separate repeated-policy validation, not this one-step
observation or a repeat of the rejected simple E4 trial. Full-history global
checks still scale with sequence length; this task does not certify unlimited
live operation. Stop here.
