OUTCOME
The experimental candidate removes the tested arbitrary-world-origin dependence,
but DOES NOT materially suppress Kimera's first-belief rotation/bias response.
It passes the predeclared coordinate gates with unchanged native thresholds.
No production patch or full sequence was run. This is a useful negative causal
result: correcting this numerical inconsistency is not, by itself, the solution
to the large first-event response. It does not prove the full zigzag is fixed,
nor rule out effects of different cache history over a longer run.

INTERVENTION AND SCOPE
First LEFT camera in each track's native observation order defines the local
frame. Native algebraic DLT uses locally expressed mono cameras; a valid point
is transformed back. Stereo right-camera baseline, missing-right handling and
measurement order match native code. Same rank tolerance1, cheirality,10m
distance,3px max reprojection, sigma3, EPI=false, LOST=false, smart Jacobians
and Schur elimination. This changes the algebraic numerical representation,
so landmark estimates and rank/rejection outcomes can change even though
thresholds and physical data do not. No claim of original algorithm equivalence.

Private harness calls native decideIfTriangulate before native linearization.
Only a normal freshness trigger installs a candidate point/status and current
camera cache. Original warm history is preserved. Function/parameter/measurement/
calibration/body/key bytes are checked unchanged. Production headers/binaries
untouched; no source replay or full-trajectory scoring, no covariance tuning.

INTERPRETATION / DECISION
CP60 established a real coordinate-consistency problem in native algebraic
triangulation/rejection. CP61 demonstrates a deterministic local-frame remedy
for the tested coordinate sensitivity without relaxing rejection thresholds.
However, fixing that sensitivity barely changes this first saved response.
Do not present it as THE CBS-ON zigzag bug or promote a full rerun on this basis.

Chronology matters: the large ordinary-step rotation response precedes the
retriangulation/support loss measured at refresh. Those subsequent losses can
modify refresh, but cannot be the trigger of that already completed first
ordinary-step response. This does not exclude pre-existing visual weaknesses,
other smart-factor issues, or later accumulation. Original-conditioned cached
history remains a stated limitation; there is no propagated-candidate result.

Stay on suspect1 as requested. This narrows the world-origin branch for the
first event; it does not silently close all suspect1 or advance to suspect2.
No further experiment is launched. The next decision should explicitly separate
the remaining historical-cache question from the already tested first-event
retriangulation effects; do not repeat origin shifts or tune a favorable frame.
