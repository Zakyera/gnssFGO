Conclusion
==========
The saved-state check localizes a concrete numerical weakness to the velocity
and angular-rate derivatives of the interpolated source factors. The existing
closed-form derivatives agree substantially better with independent direct
factor-residual differences. This justifies a narrow derivative-only candidate,
not a blanket switch of all Jacobians and not a claim that convergence is fixed.

No estimator, replay or optimizer was run. No production code, covariance,
threshold, lag, prior, support clock or measurement model was changed.

Method
======
Native factors use the frozen SourceWnoaModel.h and existing numerical branches.
Alternatives use the existing GPWNOAInterpolator and GPWNOAPrior analytic/hybrid
branches. No new factor residual or covariance formula was introduced.
Independent reference: five-point central differences of the directly whitened
factor residual, at steps 1e-3, 1e-4 and 1e-5 in local coordinates. These are
diagnostic perturbations, not changes to the optimizer or its step settings.
J^T r and diagonal J^T J were summed factorwise for the selected coordinates.

For both source velocity and angular-rate blocks, the existing analytic path

discrepancy is larger with the analytic/hybrid branch, although its relative
size is only 3.55e-9. This is not sufficient to declare that branch incorrect.
It also contains a numerical derivative of the inverse right Jacobian.

With endpoints fixed, interpolation's tangent argument is linear in endpoint
twists; existing velocity/angular-rate derivatives can follow its chain rule
without differencing interpolated world poses. Small differencing errors can
matter when whitened J^T r contributions almost cancel. This mechanism is
consistent with the evidence, not proof that every stopping failure has it.
