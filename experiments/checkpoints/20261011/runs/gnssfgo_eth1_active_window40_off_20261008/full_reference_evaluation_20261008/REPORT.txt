Reference and conventions
-------------------------
GrandTour mission: 2024-10-01-11-29-55 (ETH1), bag offset 0, requested 40 s.
Reference: 2024-10-01-11-29-55_cpt7_ie_tc.bag
Topic: /boxi/inertial_explorer/tc/odometry
Frame: enu_origin; child: cpt7_imu.
There are 8000 reference samples during the first 40 s, with maximum gap
0.005000114 s. Every saved estimator pose has valid bracketing reference.
This is the dataset's CPT7 Inertial Explorer tightly coupled GNSS/INS reference.
It shares CPT7 measurements with the native estimators; it is NOT independent
Leica/AP20 prism ground truth. These ATE values are a different reference
comparison from the previous prism ATE and must never be silently mixed.

Reference position interpolation is linear, orientation is SLERP; no
extrapolation; maximum permitted reference interval 0.05 s. Both estimated and
reference CPT7 poses are converted to the same physical prism point using the
unchanged evaluation lever arm. A single rigid SE(3), scale=1 Kabsch alignment
is fitted over each complete evaluated path. No per-section alignment.
Position ATE RMSE is sqrt(mean(||aligned_estimate-reference||^2)).

Validation / reproducibility
---------------------------
evaluate.py reuses retained reference loaders, lever arm, interpolation and
Kabsch implementations. summary.json records every input path and SHA-256,
full/common metrics, alignment transforms, timestamps and coverage.
14 frozen evaluation input hashes were checked before AND after evaluation:
no mismatch. Every native/fused saved row is scored; no unmatched reference
pose; eight identical common time masks. Synthetic rigid alignment, rejection
of extrapolation and rejection of oversized reference gaps passed.
verify_evo.py independently aligns/scores all 16 full/common products using
evo. All passed; maximum RMSE discrepancy = 5.742628594873622e-14 m.
The exported *_prism.tum files are position-APE audit products: positions are
at the prism point; their orientation fields retain CPT7 orientation and must
not be reused as full prism-frame poses for rotational/RPE evaluation.
Per-pose errors and sampled references are retained. No old evaluation or
source artifact was overwritten; no estimator code or configuration changed.
