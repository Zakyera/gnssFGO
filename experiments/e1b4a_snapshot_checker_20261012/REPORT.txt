IMPLEMENTATION

ExactGpuSnapshot.h/.cpp:
- Test-only friend declarations in five private header copies. No production
  source edits, new data members, vtable changes or estimator DSO rebuilds.
- Copy current factor type/keys, fixed unary target, linearization point,
  pending full Hessian/error results, offloading/surface-validation settings,
  inlier thresholds, count, valid index list and evaluation anchor.
- Exact device-to-device copy of factor-visible source points/covariances/
  normals and voxel hash buckets/means/covariances. No voxel-map reconstruction
  or CPU-double round trip. Geometry is deduplicated within a branch only;
  source, ordinary and batched branches never share its GPU storage.
- Each factor owns independent derivatives, stream, scratch and inlier buffers.
  Ordinary clone() is untouched and is not used for VGICP snapshots.
- Preserve duplicate factor identity within a branch, null slots and types;
  explicitly preserve LinearDampingFactor's derived type and owned matrix.
  Inherited LinearContainerFactor::clone() alone would erase that type.
- The original inlier-anchor device pointer may refer to completed batch
  scratch. Do not dereference/copy that address. Recreate owned device storage
  from the identical CPU anchor recorded by reset_inliers().
- Snapshot only defined, semantically live data. Fresh uninitialized anchor
  fields and the write-only device reduction-count scratch are not read.
  Unused capacity, object addresses, padding and geometry offload/LRU metadata
  are not mathematical state. This is not a generic PointCloud clone.

LocalUpdateCheck.h:
- Copy the actual clean LOCAL smoother, including its parameters, timestamp
  maps, Values, delta, factor slots, update counters and fixed-variable data.
  GTSAM's existing BayesTree copy clones clique structure. Detach nonlinear
  factors, linear factors, conditionals and cached Gaussian factors explicitly.
- Existing copies omit lazy separator/marginal query caches; these are rebuilt
  on independent snapshots for comparison, not used as solver input or silently
  approximated. No source factor is evaluated for covariance diagnostics.
- Construct two independent checkpoint branches. Feed the identical incoming
  factors/Values/timestamps/removal slots; ordinary update in one, frozen scoped
  batching in the other. Check estimate, theta, graph structure and decisions,
  per-factor Gaussian matrices, full covariance and latest relative covariance.
- finish(authoritative) separately compares the ordinary branch against the
  actual ordinary solver after its update. Thus matching two faulty copies is
  not the sole oracle. Unknown factors/values and unsupported GBP/diagnostic
  sidecar states fail closed. Exceptions stay in disposable diagnostic branches.
- The diagnostic does NOT wrap/enable a production update yet. Integration must
  occur outside any batching scope; ordinary source execution remains primary.
  Diagnostic failure must be made visible to the bounded-capture controller,
  not swallowed by the bridge's usual warning-only exception handler.

LIMITS / NEXT GATE

This is an in-process exact-boundary LOCAL checker, not a serialized frontend
restart system. A future real capture must call it on the serialized LOCAL
thread while factors/geometry are not concurrently mutated. cudaDeviceSynchronize
drains device work but is not a concurrency lock. Nonresident or unknown inputs
must STOP that validation, not silently use a fresh factor.

integrate this observer into a separate diagnostic wrapper and sample a short

and must never be counted as the candidate's production runtime.
