1. What changed, and what did not
================================
Private directory only: experiments/fixed_lag_native_fl3h_20261014/.
RecordedFixedLagSmoother is the authors' existing gnssFGO fixed-lag smoother
under a private name. One read-only callback captures outgoing states from an
ISAM2 COPY immediately before marginalizeLeaves. This observes the actual
retirement estimate, after the normal update, without perturbing mutable delta
in the running solver. Validation normalizes the class/helper names and hook
and verifies the remainder exactly against the original authored source.

NativeSmoother keeps the original LinearContainerFactors and marginal-connected
fixed linearization points. FIXED means the linearization point, not a frozen
pose estimate. There is no custom AnchoredMarginal conversion, retained-graph
reload, clearing fixed keys, or repeated pre/post whole-window convergence loop.
The chart-converted audit view is used ONLY on disposable diagnostic copies.

Receiver reuses FL2b transactional lifecycle, revision ownership, pending-event
handling, absorption ledger and independent support clock. Each support/source
version receives its ordinary incremental update; revision replacement retains
the existing force_relinearize=true policy. At a retirement publication there
is ONE additional stock update plus marginalizeLeaves. This is not one solver
call for all source revisions in an entire 100ms interval: all versions remain
individually processed. EOF emits the existing incremental state, with no hidden
batch optimization. Outputs explicitly say *_incremental / not_checked.

Frozen model/settings: 7s lag, independent100ms supports,59-sample clock origin,
X/V/W state, WNOA Qc variances[.00375,.00375,.00375,.015,.015,.015], initial
pose/V/W sigmas1e-5/10/3, Gaussian source covariance scale1, no central IMU/GNSS,
same interpolated physical endpoints and source availability/revision order.
Classic active_window_temporary source journal is unchanged; downstream stable
ID replacement remains distinct from source-to-source CBS. No coalescing.
Ordinary iSAM2 GN/QR, relinearization threshold.01, skip1, unused-slot reuse on.

Output distinction:
  online_incremental: immutable newest-state output at each support arrival;
  finalized_incremental: each historical pose captured once as it retires,
    followed by the remaining active states at EOF. Not full retrospective
    smoothing, and never labelled online.
The retained full-history reference has separate as-played and final outputs.
