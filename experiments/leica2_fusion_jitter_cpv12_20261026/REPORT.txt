4. WHAT WAS / WAS NOT TRACED

The original receiver code inserts a predicted new support state, adds its
WNOA motion factor, dispatches pending beliefs, performs retirement if needed,
then saves the newest state. Beliefs arriving between support cycles can revise
the graph without rewriting the preceding ONLINE row. The saved append-only
file therefore connects states produced with different available information.

Using the actual saved velocity/angular rate, an independent SE(3) exponential
predicts 100ms ahead from the PREVIOUS SAVED first-publication state. Difference
to the next publication in the selected window:
  OFF median 9.35cm, p95 15.61cm, max 23.61cm.
  ON  median 3.74cm, p95  7.72cm, max 14.23cm.
This is NET departure from a stale saved prediction, not the actual internal
pre-update innovation. Between publications, the previous support can already
have been corrected. Predictions matched independent 4x4 matrix exponential
calculations within 7.11e-15 in the checked poses.

Important recording limit: commits save applied belief payloads and publication/
retirement states, but NOT fused pre/post states for every source factor and
NOT simultaneous snapshots of all active states. It is impossible to recover
individual source-induced pose changes uniquely from these logs alone.
Hence the proposed exact per-update causal trace is still OPEN. This audit
does not silently infer missing internal states from final trajectories.

5. WHAT THIS MEANS FOR THE SUPERVISOR'S PRIOR HYPOTHESIS

The original receiver binary, launch wrapper, NativeSmoother and Receiver.h
match protected capture hashes. The initial position/orientation anchor is
already tight (sigma=1e-5 in each pose tangent component). The separate initial
linear/angular velocity priors are much looser (sigma 10 and 3); this is not a
claim that every startup prior is tight. The inspected problem is ~383s later.

The WNOA Qc remains [.00375,.00375,.00375,.015,.015,.015] as variances, with
rotation first. A weaker motion prior RELATIVE to source information could
permit larger newest-state changes, so the supervisor's hypothesis remains
plausible. However, the SAME Qc produces a much smoother delayed path, and the
ONLINE error follows a precise alternating information schedule. We have not
measured current factor Jacobians/information, marginal-prior conditioning or
nonlinear stationarity. Raw Qc and source covariance traces are not comparable
strengths because they describe different quantities and time mappings.

For completeness, selected applied-version covariance trace medians (OFF):
GLIM rotation 4.331e-8, translation 2.152e-6;
Kimera rotation 1.437e-8, translation 5.603e-7.
These are unmatched age-weighted revision cohorts, not independent evidence or
proof that Kimera dominates the coupled graph. Do not use them to choose Qc.

No evidence here justifies tightening the initial anchor, scaling the
marginalization prior, or immediately tuning Qc until the picture looks smooth.
A stronger motion prior might reduce output jitter but also suppress real
motion. The global ATE table demonstrates why smoothness alone is insufficient.

6. RECOMMENDED NEXT BOUNDED TEST — NOT EXECUTED

First obtain a same-input, UNCHANGED-MODEL receiver-only diagnostic replay with
read-only observation of one short selected interval. Saved events already
exist; no GLIM/Kimera sensor rerun is required. Because no resumable solver
snapshot was saved, replay must establish the original history from startup;
only the bounded interval needs detailed observations. Do not start at 380s
with an empty graph and call it equivalent.

Validate original output/commit parity, then observe newest and previous-state
poses before/after: each source replacement/insert, support addition/pending
dispatch and retirement. Save simultaneous active-window snapshots, source
residuals, WNOA residuals and marginal contribution without changing solve order.
This separates newest-state extrapolation, update-order/linearization effects,
historical-frame corrections and relative information weighting.

Only after that evidence choose ONE intervention. If the motion factor is the
limiting term, a separately authorized single Qc ablation should compare jitter,
ATE/RPE and maneuver/latency response on untouched windows too. If publication
timing or state consistency is the limiting term, address that explicitly,
without calling a delayed output real-time. No parameter sweep is authorized.
