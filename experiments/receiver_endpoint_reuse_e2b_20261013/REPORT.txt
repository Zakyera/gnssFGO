1. Scope and hypothesis

Reuse the same WNOA endpoint pose and endpoint Jacobians when multiple source
factors ask for them with bit-identical inputs. This addresses repeated work
measured by S5c, not the state/history growth or all of the receiver's cost.

These are CACHE disabled/enabled comparisons on ONE existing CBS-ON journal.
They are NOT new CBS-OFF/ON experiments and NOT live co-running estimators.
No GLIM/Kimera source, bag, fusion-model, noise, covariance or policy change.

Preserved: source_wnoa X/V/W; independent 100 ms support clock; full-history
iSAM2 QR; every ordered stable-ID revision replacement; Gaussian scale 1;
Qc [.00375,.00375,.00375,.015,.015,.015]; original priors/initialization and
strict 1e-5 normalized-gradient/transactional publication rules. There are no
central IMU measurement factors. uniform_imu names the existing clock policy.

2. Implementation and exactness boundary

Private switch E2B_ENDPOINT_CACHE=1; unset/0 means disabled. Existing whole-
factor E2 memoization stays enabled in both controls. Production CMake targets,
installed libraries and executables are untouched.

SourceWnoaModel.h keeps the original poseUncached computation: same numeric
pose derivatives and same author-library analytic V/W blocks. The cache shares
its results, not a new derivative formula. Relative composition, measured mean,
full source covariance, whitening and factor revisions remain outside it.

ExactEndpointCache.h: fixed 8192-entry LRU, mutex-protected lookup/commit,
deep-copy results, compute outside the lock. Concurrent cold duplicate misses
may recompute, never expose mutable cached values. Hashes only index buckets;
full vector equality decides a hit. Eviction never changes a returned result.
Exceptions/nonfinite outputs are not cached. Failed solver branches can leave
memo entries, but a restored state can reuse only its exact input signature.

Key: endpoint support keys; exact X/V/W stored representations; physical
timestamp; dt/tau; full actual Qc matrix; fixed interpolation flags; requested
Jacobian/no-Jacobian mode; evaluation rounding mode. Factory-owned interpolators
are immutable. Public pointer replacement bypasses reuse. Keys cover the frozen
library/runtime and factory path used here, not arbitrary mutated third-party
interpolators or changing floating-point environments during construction.

Only two replay-TU additions: pass the physical endpoint timestamp to its
factory and flush cumulative cache diagnostics after existing publication
refinement. Cache diagnostic overhead is included in timings.

6. Limits and next decision

This is a real but partial receiver speedup. Late enabled publication p95 is
still 1.316–1.321 s, and total service-interval p95 is 1.464–1.469 s, above the nominal
1 s/support wall budget at 0.1x. Late non-recovery publication p95 is still about
1.093 s. 26/25 enabled support publications exceed 1 s, versus 36/35 disabled.
This does not certify a new 160 s live run or eliminate the long-duration problem.

The cache does not remove the 10.09 million necessary misses, Gaussian QR,
WNOA motion evaluations, full-history graph growth, or refinement passes. The
old S5c percentages describe the old profile, not a freshly measured E2b profile.
Preserve this bounded improvement and choose the next isolated measured task;
do not automatically tune, change marginalization or promote/restart a live run.
