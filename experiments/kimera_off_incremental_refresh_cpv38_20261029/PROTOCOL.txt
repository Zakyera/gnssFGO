HYPOTHESIS / SINGLE CHANGE

OFF-only incremental refresh. After the normal update and before marginalizing,
promote unanchored marginal Gaussians using the unchanged CP-K9 ownership/cache
checks, then perform ONE empty iSAM2 update with force_relinearize/fullSolve.
This local pinned GTSAM implementation uses forceFullSolve to select ALL nonfixed
keys; promotion must account for every fixed key first. Full back-substitution
completes the new step. Preserve ordinary update count/cadence, timestamps,
factor slot ownership, native factors, measurements, noise and smart policies.

clearing, repeated convergence loop or nonlinear-cost acceptance. This is ONE
extra GN step per cycle, not nonlinear stationarity. GTSAM may internally take
its normal batch-reelimination path when all keys are affected.

Opt-in CPV38_OFF_REFRESH=1 requires CPK9_PRIOR_REFRESH=1, FL4Q_ENABLE=0,
FL4M_RETIREMENT=remove and existing native GN/active_window_temporary mode.
Absent/0 preserves baseline. Reject pending/applied incoming belief state.
Candidate update is transactional, including native mutable smart caches and
LOCAL marginal cache. Unsupported inputs/configurations fail closed.
