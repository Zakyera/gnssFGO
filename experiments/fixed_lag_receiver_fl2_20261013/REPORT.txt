Mechanism and code evidence
Runtime include/gtsam/nonlinear/ISAM2-impl.h:374-401 gathers relinearization
keys; forceFullSolve uses threshold0, then explicitly removes fixedVariables.
Runtime include/gtsam/nonlinear/ISAM2.h documents marginalizeLeaves fixing
linearization points, not physical state values. A new revision can move those
values while their anchors stay fixed. Standard copied updates therefore do
not guarantee stationarity of our exact current-chart retained objective.
The controlled no-retirement case passes, and an independent solve of the
same marginal-prior objective passes; the failure is localized to this boundary
linearization/refinement interaction rather than an unobservable source chain.

The pinned runtime really creates an unanchored LinearContainerFactor. Its
ordinary nonlinear error is zero. MarginalAudit evaluates the stored Gaussian
at Local(anchor,current) instead. At a displaced linear boundary point, the
recorded generic and chart-correct prior errors are0 and0.30504357376571184.

interpret its result as a valid nonlinear convergence certificate.
