WHAT WAS IMPLEMENTED
The opt-in private FL4Q_ENABLE path first tests the ordinary native update.
When its cost rises beyond1e-10*(1+abs(before)), it uses the EXISTING GTSAM
LevenbergMarquardt optimizer on a cloned graph at the initialized current
estimate. No fresh research loss, health rule or covariance scale is added.

An existing Gaussian marginal q(d)=0.5*d'H*d-eta'd+0.5*c keeps its original
anchor A and coefficients H,eta,c. Its residual coordinates remain
d=Local(A,X), even when the active nonlinear equations are refreshed at X.
Using J=D Local(A,Retract(X,epsilon)), its local Gaussian is:
  H_current = J'HJ
  eta_current = J'(eta-Hd)
  c_current = d'Hd-2eta'd+c.
FL4l's OriginalChartPrior adapter supplies this coordinate derivative using
central differences1e-6; it is tested independently here. Existing native IMU,
BetweenFactor and smart-visual measurement implementations are unchanged.
This preserves the prior FUNCTION, not a naive replacement of its anchor.

LM bounds frozen before data:10 outer iterations; lambdaInitial1e-3,
lambdaUpper1e12; diagonal numerical damping with the pinned default diagonal
limits; relative/absolute cost tolerance1e-9. A5s wall budget is checked between
iterations, not preemptively inside a library call. Each trial accepted by this
wrapper must independently lower the unchanged original-chart objective on
fresh clones. An invalid/no-decrease/budget failure throws and restores state.
There is no silent automatic retry with another method.

Accepted candidate values are NOT merely written into the output trajectory.
The private BPSAM helper rebuilds its ISAM2 core at those values with:
- original sparse factor slots and native factor pointer identities preserved;
- Gaussian priors represented by immutable original-chart adapters;
- unchanged source/CBS ownership maps, pending beliefs and parameters;
- current undamped equations, Bayes tree and cleared covariance cache;
- original ordering constraints and update counter retained;
- zero accepted delta in the new current chart, surviving calculateEstimate.
The zero delta records the accepted nonlinear point; it is NOT a claim that
this point is the exact minimum of the current undamped Gaussian. Solver
damping is discarded, never inserted into the graph or exported covariance.
Later marginalization still creates native Gaussian priors; these acquire an
immutable original chart if another fallback rebuild occurs.

Ordinary steps keep the original path. Existing temporary-CBS retirement still
removes the external factor before marginalization. Keeping an original-chart
prior does not restore retired external factors or prove independent sources.
