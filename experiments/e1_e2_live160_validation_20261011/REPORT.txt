3. Defect V2 — incomplete rollback lifecycle state machine

The original check_lifecycle.py:35 accepts only staged_residual_regression.
At stdout line91558, backend529, the actual code also performs
active_residual_regression, removing an older factor before retrying.
Its old parser also ignored active_window_remove_committed and assumed the
only checkpoint was the outer IFLS lifecycle line.

Correct contract follows the code:
- BPSAM backup at3655-3663.
- Newly staged rejection restores it, clears pending candidates and recursively
  retries at3687-3712.
- Already-active rejection restores it, commits tracked removal, supplies those
  exact slots to the recursive update at3715-3760.
- Every recursive update takes its own checkpoint; no new IFLS lifecycle line
  is emitted. The parser must checkpoint at the retry boundary as well.
- IFLS computes departing keys/removal slots before the update at156-191;
  ordinary removal is therefore separate from residual-guard removal.

New checks reconcile every active count, receiver edge and factor slot; require
that a post-solve guard's slot still refers to the same edge AFTER restoration;
reject duplicate live slots, missing commits, unmatched guards and wrong retry
counts. The original GLIM lifecycle checks are retained unchanged.

Actual successful-transaction accounting:
Kimera:775 constructions -59 undone constructions =716 retained admissions;
       698 subsequent removals,18 remaining active.
GLIM:  781 queued/admitted,756 removals,25 remaining active.

Kimera has47 staged-rollback transactions and17 active-removal transactions.
The latter cover21 individual guarded old factors;21 is NOT the number of
transactions. All restored slots and lifecycle counts reconcile. No recorded
stale-slot removal, duplicate active slot, or unaccounted source factor found.

This checks logged graph bookkeeping and successful completion, not numerical
equality to a clean source solve after every rollback. In particular, no claim
that all nonlinear history or marginal-prior information becomes independent.
